# MineSafe — recopilación de firmware ESP32

- 01: nodo físico del ZIP web (6), con plantilla de secretos.
- 02: proyecto simulador del ZIP original, con PlatformIO.
- 03: gateway recuperado del bloque C++ del consolidado P079, con credenciales ya censuradas.
- 04: versiones adicionales del nodo físico, original TXT con credenciales censuradas y versión P079.

No se ha compilado ni ejecutado el código. No se incluyen secretos reales. No se han recuperado archivos PlatformIO originales del gateway o del nodo físico en estas fuentes. No se afirma que las versiones coincidan con las instaladas. Paquete para auditoría documental, no para despliegue de seguridad minera.
